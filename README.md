# Álbum Neuronic

Álbum digital de figuritas (Vite + React).

## Desarrollo local

```bash
npm install
npm run dev
```

## Deploy en GitHub Pages

La app se publica automáticamente al hacer push a `main`.

**URL pública:** [https://facundoabba.github.io/album_neuronic/](https://facundoabba.github.io/album_neuronic/)

### Primera vez (configuración en GitHub)

1. Entrá al repo → **Settings** → **Pages**
2. En **Build and deployment** → **Source**, elegí **GitHub Actions**
3. Hacé push a `main` o ejecutá el workflow **Deploy to GitHub Pages** manualmente

En la **última página** del álbum aparece un **código QR** que apunta al repositorio: https://github.com/FacundoAbba/album_neuronic

## Assets

Coloca en `public/`:

- `tapa.png` — portada
- `fondo.png` — fondo de cada página
- `figuritas/*.png` — figuritas
